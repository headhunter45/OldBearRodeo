This project should be a simple to use and easy to host vtt. All data will be stored in local browser storage. If possible users will connect directly to each other and the server will just make the handshake between them. If not the server will relay messages to the clients.

I want to be able to load maps, and tokens on them. I want to be able to control fog of war and layers I want to be able to assign tokens statuses and track their hp as a health bar without showing the number to players. I want an initiative tracker. I want to go to this url without signing in and create a new game session using the assets I have loaded. I want to be able to have multiple maps/screens ready so I can setup the next one while the players are still on the current one and can only see that. I want to be able to copy/move tokens from one map to another and keep their state. I as the gm should be able to edit any token's hp. I want to have an invite url for my session when I create it that I can give to other players to join. These other players will then connect to the same server and see the same map/session I do. They will also have their own token they can control. I want to be able to assign them a token that they can control. I want an indicator for when they are trying to move farther than their speed. I will set their speed on the token. I would really like to be able to get their current hp and speed from their dndbeyond character. I would also like to give them a flyout view of their character if they have one linked. They should be able to edit their own hp regardless of whether they have a character linked or not. I want to add authentication eventually at least for the game master, but for now no auth is fine. If we need a db then use postgres. For our frontend I want to use vite/react/typescript. for our backend I want to use node/typescript. for our database I want to use postgres. We will use docker to containerize the application.

I should be able to easily add tokens/props/maps to my assets while playing and deploy them on the map quickly. I want a way to add rings and clip tokens to a circle if they are bigger. I should be able to have a token that has a standard ring and a flat color background in case an image doesn't fill it. I would really like this to work behind nat, but I can deploy the docker compose stack on a server with ports forwarded to it through an nginx reverse proxy. This must work on a phone with touch zooming and paning. My users will be switching between discord chat, their character sheets, and this app. I want to reduce friction wherever possible. make use of flyouts and hamburger menus. add a dice roller with icons for the dice that roll a that die and announce $name rolled $x. Have dedicated buttons for d20 with advantage and with disadvantage. allow showing a limited part of their dndbeyond character sheet if they have linked one. I want spells linked with spell descriptions even if those have to come as links to dndbeyond.

I want each user to have ways to indicate on screen. a laser pointer that highlights where their cursor is with a trail in a color they can choose. I want an arrow, a crosshair, a circle where they click at the center and move their moust outward to choose the radius. a rectangle . All of these effects should stay on screen for everyone for some time, but the timing of each effect can be different. When a player joins they should be able to customize their name. Players should only be able to move their own tokens

At some point in the future I want chat and rolling. I want voice chat and to stream audio from my computer. I want to be able to record each voice stream and the audio/effects streams separately. I want a soundboard I can load with looping or one of effects and to be able to control the relative volume of the effects and background music. I want to be able to control if the sounds are playing to players or not. I want to be able to pause, resume, restart etc.
